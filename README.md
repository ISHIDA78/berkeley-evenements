# Le Berkeley — aperçu événementiel

Version de présentation du site événementiel.

**Consulter : https://ishida78.github.io/berkeley-evenements/**

Les fichiers du site sont dans `docs/`. GitHub Pages publie la branche `main`, dossier `/docs`. Le site ne nécessite aucune compilation sur GitHub.

Les pages sont accessibles publiquement pour relecture, avec une directive noindex. Le formulaire ne transmet aucun message dans cette version statique ; les liens téléphone et email fonctionnent.

Les photos et logos sont ceux du Berkeley. Crédits photographiques : Romain Ricard et Guisarde, d’après les sources du site officiel https://www.leberkeley.com/. Ces éléments et les fontes Apercu et Bigilla ne sont pas fournis sous licence libre.

Aucun document métier interne, archive ZIP, secret ou fichier de configuration d’envoi n’est inclus.
